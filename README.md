# Voidpulse

Survivor-like mobile Android, nerveux et profond, en vectoriel néon. Hors ligne, sans achat intégré ni publicité.

- Architecture : [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## Démarrage

```bash
npm ci
npm run dev        # serveur de développement
npm run check      # lint + typecheck + tests + build
```

## Conventions

Commits conventionnels obligatoires (`feat:`, `fix:`, `perf:`…), vérifiés localement (husky) et en CI.
